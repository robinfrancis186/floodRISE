# `@floodrise/map`

Chennai replay and Kerala geographic map surfaces shared by the floodRISE operations console and field PWA. MapLibre GL JS displays detailed OpenStreetMap street tiles with deterministic flood-response GeoJSON overlays. A packaged road snapshot remains available when tiles fail or the map is explicitly configured offline.

```tsx
import { FloodMap, type FloodMapSelection, type MapHorizon } from "@floodrise/map";

const [horizon, setHorizon] = useState<MapHorizon>("now");

<FloodMap
  variant="operations"
  horizon={horizon}
  onHorizonChange={setHorizon}
  onFeatureSelect={(feature: FloodMapSelection) => setSelectedId(feature.id)}
/>;
```

## Component contract

- `variant`: `operations | signals | resilience | field`
- `horizon`: optional controlled `now | 1h | 3h` value
- `onHorizonChange`: receives the selected horizon
- `selectedFeatureId`: optional controlled feature selection; pass `null` to clear it
- `onFeatureSelect`: receives `{ id, kind, name, description, confidence, coordinates, properties }`
- `height`: CSS height or numeric pixel height for the complete map surface; `100%` fills a sized parent
- `showSummary`: displays a synchronized, keyboard-operable list below the map; screen-reader descriptions remain available when false
- `showHorizonControl`: hides the package control when a surrounding view already provides an equivalent horizon selector; controlled horizons without `onHorizonChange` are displayed as fixed layers without inert buttons
- `interactive`: disables map gestures and controls when false
- `allowRegionSwitch`: exposes Chennai/Kerala geography selection (off by default); `onBaselineChange` receives `chennai | kerala` so callers can hide scenario-only controls
- `selectedLocation`: controlled `[longitude, latitude]` report pin; `onLocationSelect` receives a clicked coordinate and enables report-location selection instead of scenario selection
- `ariaLabel`, `className`: accessible labeling and layout integration

The package imports MapLibre's required CSS and its own styles automatically. The optional `@floodrise/map/styles.css` export is available for consumers that manage CSS explicitly.

All rendered scenario layers are clearly marked `DEMO DATA • NOT LIVE`. Predictions use “rapid impact estimate,” routes use “lower-risk route,” and community evidence is never presented as official confirmation.

By default, street tiles load directly from `https://tile.openstreetmap.org/{z}/{x}/{y}.png`, with visible attribution and normal browser caching. Only viewed tiles are requested; the field PWA does not download them for offline use. Zoom to level 19 for buildings, local streets, and mapped places. Set `VITE_OSM_TILE_URL` to another HTTPS raster template (or loopback HTTP), or to an empty string for the packaged offline map. Community tiles have no availability guarantee; a real emergency deployment should use a tile service with suitable availability or a self-hosted server. See the [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/).

The road baseline is generated by `pnpm osm:import`, distributed under ODbL 1.0, and visibly credited as `© OpenStreetMap contributors`. Production imports use the Geofabrik Southern Zone extract rather than a public tile server.

## Facility search and offline coverage

Both main app maps enable the region switch. **Places** opens a searchable,
keyboard-operable panel with hospital, police, fire station, school, college,
and community-centre filters. Nearby lists use straight-line distance from the
map centre, not route distance. Grouped markers expand when selected; individual
records link to their original OpenStreetMap node or way.

The packaged datasets contain 637 Chennai and 23,586 Kerala records. The Kerala
snapshot loads on demand; a failed download leaves the current region intact.
The built field PWA caches this public snapshot after a successful first load.
These facility records do not establish current access, capacity, opening hours,
or shelter activation. Kerala mode hides Chennai flood estimates and scenario
markers; reporting workflows still belong to the Chennai demo incident.

Offline facility data does not imply offline street-tile coverage. Only Chennai
has a packaged road fallback. Panel scrolling stays inside the map panel and
leaves the map canvas and OSM attribution in place.
