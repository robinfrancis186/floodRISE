# Fixture provenance and licences

- Flood extents, scenario measurements, reports, shelter capacities, decisions, and timelines in this bundle are synthetic and released with this repository for demonstration and testing.
- `osm-baseline.geojson` contains a packaged OpenStreetMap road snapshot for the Chennai area, captured through the Overpass API at `2026-07-20T15:45:19Z`. It is derived from OpenStreetMap data and distributed under the Open Data Commons Open Database License (ODbL) 1.0. Attribution: `© OpenStreetMap contributors`. See <https://www.openstreetmap.org/copyright>.
- The production adapter catalogue uses versioned Geofabrik Southern Zone extracts for OpenStreetMap roads. Copernicus GFM/GLO-30, GHSL, IMD, CWC/NWDP, Census of India, and authorized GCC/TNSDMA datasets are not copied into this fixture bundle.
- Implementers must retain provider attribution and licence metadata for any real imported artifact. Publicly queryable GCC/Chennai services must not be persisted or redistributed without written authorization.
